Hvilken organisering setter oss best i stand til å møte markedet?

Vurderingen kombinerer markedsposisjon, gjennomføringsevne, produktifisering, intern samhandling og økonomisk potensial.

Konklusjon

Alternativ 4 — CSNE + Automasjon + Telekom — gir best markedsposisjon og høyest økonomisk potensial. Det er det eneste alternativet som samtidig samler nødvendig teknisk dybde, støtter produktifisering, reduserer personavhengighet og kan levere både internt i prosjekter og direkte til kunder.

Detaljert vurdering per alternativ

Alternativ 1

Fortsette som før + koordinering på tvers

Markedsposisjon: Svak til moderat • Score 2.1/5

Lavfriksjonsmodell med felles forum, metodeverk og koordineringsmekanismer, men uten sterk sentral leveransefunksjon.

Fordeler

  • Lav organisatorisk motstand og rask å etablere.
  • Bevarer eksisterende markedsområdeansvar og kundegrensesnitt.
  • Kan gi rask minimumskoordinering av maler, kravbibliotek og fagforum.
  • Krever lavest initial investering.

Ulemper

  • Siloene består i praksis dersom insentiver ikke endres.
  • Telekom-, nettverks- og OT-ressurser forblir spredt og personavhengige.
  • Svak markedsprofil; kundene ser ikke et tydelig Norconsult-kraftsenter.
  • Lite egnet for produktifisering, fastpris og skalerbar leveransemodell.

Risikoer

  • Blir en faggruppe uten myndighet.
  • Konkurrenter tar markedet mens Norconsult koordinerer internt.
  • Lav evne til å bygge referanser raskt.

Passer best: Passer kun som kort overgang eller minimumstiltak dersom ledelsen ikke er klar for sterkere grep.

Anbefaling: Ikke anbefalt som hovedmodell. For svak til å ta markedsposisjon.

Alternativ 2

Automasjonsavdeling

Markedsposisjon: Moderat • Score 2.8/5

Satsningen plasseres primært rundt automasjon, OT og tekniske prosjektleveranser.

Fordeler

  • Sterk nærhet til OT, PLS, SCADA, byggautomasjon og tekniske anlegg.
  • God praktisk troverdighet i prosjekter og hos driftsmiljøer.
  • Egnet for IEC 62443, sone/conduit, FAT/SAT og leverandørkrav.
  • Kan raskt skape verdi i eksisterende prosjekter.

Ulemper

  • Kan bli oppfattet som et automasjons-/PLS-miljø, ikke et strategisk cyber- og nettverksmiljø.
  • Telekom, AI governance, ledelsesrådgivning og regulatorisk compliance kan bli underprioritert.
  • Svakere posisjon mot toppledelse, kommuner og samfunnskritiske eiere.
  • Kan bli for prosjektorientert og for lite produkt-/tjenestefokusert.

Risikoer

  • Markedet oppfatter ikke Norconsult som fullverdig cyberrådgiver.
  • For smal profil gir lavere pris- og marginpotensial.
  • Intern kamp med nettverk/telekom/cyberressurser som ligger andre steder.

Passer best: Passer for tekniske OT-prosjekter, men må kobles med CSNE og telekom for å bli strategisk nok.

Anbefaling: God komponent, men ikke tilstrekkelig som hovedmodell.

Alternativ 3

Totalforsvarsavdeling / sikkerhetsfokusert task force

Markedsposisjon: Moderat til sterk, men avhengig av avgrensning • Score 3.2/5

Samler sikkerhet, beredskap, robusthet, digital sikkerhet og kritisk infrastruktur i en bred strategisk enhet.

Fordeler

  • Sterk strategisk fortelling mot samfunnskritiske kunder og offentlig sektor.
  • Kobler fysisk sikkerhet, beredskap, digital sikkerhet og robusthet.
  • Gir god ledelsesdialog og kan støtte Norconsults samfunnsrolle.
  • Kan samle flere spredte sikkerhetsfag under en tydelig paraply.

Ulemper

  • Kan bli for bred og vanskelig å selge som konkrete tjenester.
  • Risiko for at OT, nettverk, telekom og automasjon drukner i strategi og policy.
  • Krever høy modenhet i porteføljestyring for å unngå diffus leveransemodell.
  • Kan bli tung å bygge og dyrere å skalere enn mer presis CSNE-modell.

Risikoer

  • Uklart kjøpsobjekt for kunden.
  • For mange temaer gir lav leveransekraft.
  • Kan bli mer samfunnsposisjonering enn lønnsom tjenestemaskin.

Passer best: Passer som strategisk paraply og narrativ, særlig mot offentlig sektor og totalforsvar.

Anbefaling: Bør brukes som posisjonering, men ikke alene som operativ modell.

Alternativ 4

CSNE + Automasjon + Telekom

Markedsposisjon: Sterkest • Score 4.7/5

Tverrmarkeds kraftsenter som samler cyber security, network engineering, telekom, OT, automasjon, IEC 62443 og AI governance.

Fordeler

  • Treffer kundens reelle behov: OT + cyber + nettverk + telekom + automasjon + AI.
  • Gir tydelig markedsposisjon og god teknisk troverdighet.
  • Best egnet for produktifisering, fastpris, intern prosjektstøtte og direkte rådgivning.
  • Samler spredt spisskompetanse og reduserer personavhengighet.
  • Kan levere både kommersiell verdi og totalforsvarsbidrag.

Ulemper

  • Krever sterkt konsernmandat og aktiv endringsledelse.
  • Må håndtere gruppeledere som beskytter egne ressurser og budsjetter.
  • Krever inntektsdeling, ressursallokering og felles prioriteringsmodell.
  • Høyere initial investering enn lavfriksjonsalternativer.

Risikoer

  • Intern motstand kan forsinke etablering.
  • Uten felles insentivmodell kan markedsområder omgå kraftsenteret.
  • Hvis det blir personnettverk fremfor produktfunksjon, svekkes skalerbarheten.

Passer best: Best for å møte markedet raskt, bygge posisjon, produktifisere tjenester og levere på tvers av Norconsult.

Anbefaling: Anbefalt hovedmodell. Gir best markedsposisjon og høyest 5-års resultat.

Alternativ 5

Houmb AS / kjøp eller partnerskap

Markedsposisjon: Sterk som akselerator, svak alene • Score 3.6/5

Kjøp, partnerskap eller strategisk samarbeid med spissmiljø som akselerator for kompetanse og markedstroverdighet.

Fordeler

  • Rask tilgang på spisskompetanse, referanser og metodikk.
  • Kan redusere tid til marked og gi høyere troverdighet i krevende oppdrag.
  • Kan fungere som katalysator for intern kulturendring.
  • Kan kombineres med CSNE + Automasjon + Telekom for raskere skalering.

Ulemper

  • Høyere initial kapitalbinding og integrasjonsrisiko.
  • Oppkjøp eller partnerskap løser ikke alene interne siloer og insentiver.
  • Kan bli personavhengig dersom nøkkelpersoner slutter.
  • Kan skape friksjon mot eksisterende fagmiljøer.

Risikoer

  • Man kjøper kompetanse, men ikke nødvendigvis organisatorisk gjennomføringsevne.
  • Kultur- og insentivkonflikter kan spise opp gevinsten.
  • Dyr inngang dersom markedet allerede prises høyt.

Passer best: Passer som akselerator kombinert med intern kraftsentermodell.

Anbefaling: Bør vurderes som supplement til alternativ 4, ikke som erstatning.
