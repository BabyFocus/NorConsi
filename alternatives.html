Organisasjonsalternativer

Evaluering av fem mulige modeller

Formålet er å skille mellom lavfriksjonsløsninger, tekniske fagavdelinger, strategiske paraplyer, anbefalt kraftsentermodell og mulig ekstern akselerator.

Kort konklusjon

Alternativ 4 — CSNE + Automasjon — gir best balanse mellom teknisk troverdighet, kommersiell tydelighet og strategisk gjennomføringskraft. Alternativ 5 kan være en akselerator, men erstatter ikke behovet for intern organisering.

Alternativ 1

Fortsette som før, men koordinere på tvers

Samlet vurdering: Lav–middels

Anbefaling: Bør kun brukes som minimumstiltak eller overgangsmodell.

Markedsområdene består som i dag, men det etableres selskapsmessige mekanismer for koordinering, felles metodikk, felles kravbibliotek og felles salgsstøtte.

Fordeler

  • Lav organisatorisk friksjon og rask å innføre.
  • Bevarer eksisterende kundeansvar og P&L-struktur.
  • Kan fungere som lavterskel start dersom ledelsen ikke vil etablere ny enhet umiddelbart.
  • Gir noe samordning av metodeverk, tilbud og kompetanse.

Ulemper

  • Siloene består i praksis dersom insentiver ikke endres.
  • Ingen tydelig markedsidentitet eller nasjonalt kraftsenter.
  • Kompetansebygging blir treg og personavhengig.
  • Risiko for at cyber blir tilleggspunkt i prosjekter, ikke strategisk satsning.

Viktige risikoer

  • Blir en faggruppe uten reell myndighet.
  • Markedsområder prioriterer kortsiktig egen inntjening fremfor felles posisjon.
  • Konkurrenter tar premissgiverrollen før Norconsult klarer å mobilisere.

Passer best når: Kort overgangsfase, eller dersom organisasjonen ikke er klar for dedikert satsning.

Forutsetninger for å lykkes: Må ha konsernforankret krav om bruk av felles metodeverk, definert inntektsdeling og obligatorisk involvering i strategiske tilbud.

Alternativ 2

Automasjonsavdeling

Samlet vurdering: Middels

Anbefaling: God teknisk base, men for smal alene.

Samle satsningen primært rundt automasjon, PLS/SCADA, OT-design, industriell nettverksteknikk og tekniske prosjektleveranser.

Fordeler

  • Nærmest de faktiske OT-systemene og anleggene.
  • Sterk troverdighet i tekniske prosjekter og hos driftsmiljøer.
  • God plattform for IEC 62443, sone/conduit, FAT/SAT og leverandørkrav.
  • Kan raskt skape praktisk verdi i prosjekter.

Ulemper

  • Kan bli oppfattet som PLS/SCADA-fag, ikke strategisk cybersikkerhet.
  • Risikerer å undervurdere juridisk, ledelsesmessig, AI- og totalforsvarsdimensjon.
  • Kan få svakere kobling til IT-sikkerhet, governance og compliance.
  • Kan bli for lite synlig for toppledelse hos kundene.

Viktige risikoer

  • Blir teknisk leveranseavdeling uten kommersiell premiumposisjon.
  • For lite mandat til å påvirke anskaffelser og konsern-/kommunenivå hos kunder.
  • Mangler bredde til NIS2/CRA/AI governance og styreansvar.

Passer best når: Kunder med konkrete OT-prosjekter, modernisering av automasjon, nettverksdesign og teknisk verifikasjon.

Forutsetninger for å lykkes: Må kobles tett med cyber governance, nettverk, compliance og forretningsutvikling.

Alternativ 3

Totalforsvarsavdeling / sikkerhetsfokusert task force

Samlet vurdering: Middels–høy

Anbefaling: Sterkt strategisk narrativ, men må avgrenses for å bli kommersielt presist.

Etablere en samlet sikkerhetsfokusert task force med totalforsvar, beredskap, fysisk sikkerhet, digital sikkerhet, kritisk infrastruktur og organisatorisk robusthet som ramme.

Fordeler

  • Sterk posisjonering mot samfunnskritiske kunder og offentlig sektor.
  • Kobler digital sikkerhet, fysisk infrastruktur, beredskap og robusthet.
  • Gir tyngde i ledelsesdialog og strategiske diskusjoner.
  • Kan samle flere sikkerhetsfag som i dag ligger spredt.

Ulemper

  • Kan bli for bredt og uklart som kommersiell tjeneste.
  • Risiko for at OT, nettverk og automasjon drukner i beredskaps- og policytema.
  • Kan bli vanskelig å bemanne med riktig teknisk dybde.
  • Kan oppfattes som politisk/strategisk mer enn operativt nyttig.

Viktige risikoer

  • For bred portefølje gir lav leveransekraft.
  • Uklar P&L og uklart eierskap mellom markedsområder.
  • Kundene ser ikke konkret hva de kan kjøpe.

Passer best når: Ledelsesrådgivning, sektorstrategi, kommuner, offentlig infrastruktur og beredskapsrelaterte programmer.

Forutsetninger for å lykkes: Bør brukes som strategisk paraply, men med tydelige produktlinjer for OT, cyber, nettverk og AI.

Alternativ 4

CSNE + Automasjon

Samlet vurdering: Høy

Anbefaling: Anbefalt hovedmodell.

Etablere et kraftsenter som kombinerer cyber security, network engineering, OT, automasjon, IEC 62443, verifikasjon og AI governance.

Fordeler

  • Treffer det reelle kundebehovet: OT + nettverk + cyber + automasjon + compliance.
  • Kombinerer teknisk dybde med regulatorisk og kommersiell relevans.
  • Egner seg godt for produktifiserte leveranser, rammeavtaler og managed advisory.
  • Kan være premissgiver i prosjekter før løsningene anskaffes og bygges.
  • Gir tydelig markedsposisjon uten å bli for bredt.

Ulemper

  • Krever sterkt mandat på tvers av markedsområder.
  • Kan skape intern kamp om kunder, timer og resultatføring.
  • Må rekruttere eller utvikle spisskompetanse raskt.
  • Krever aktiv ledelse for å unngå at nettverk/cyber og automasjon blir separate sub-siloer.

Viktige risikoer

  • Uten inntektsdelingsmodell kan markedsområder motarbeide eller omgå enheten.
  • For svak seniorbemanning gir lav troverdighet mot krevende kunder.
  • Hvis den må levere normal margin fra dag én, bygges ikke metodeverk og marked raskt nok.

Passer best når: Kritisk infrastruktur, industri, VA, energi, samferdsel, havn, byggautomasjon og prosjekter med OT/IT-grensesnitt.

Forutsetninger for å lykkes: Bør etableres som task force med 18–24 mnd oppstartsmandat, lavere profittkrav og harde KPI-er.

Alternativ 5

Houmb AS / kjøp eller partnerskap

Samlet vurdering: Middels–høy som akselerator

Anbefaling: Bør vurderes som akselerator, ikke som eneste strategi.

Kjøp, strategisk partnerskap eller tett samarbeid med et spesialisert miljø for å raskt tilføre spisskompetanse, metodeverk, kunder eller sertifiseringer.

Fordeler

  • Rask tilgang på kompetanse og markedstroverdighet.
  • Kan redusere tid til første modne leveranse.
  • Kan gi sertifiseringer, referanser og seniorprofiler som ellers tar lang tid å bygge.
  • Kan fungere som katalysator for intern kulturendring.

Ulemper

  • Integrasjonsrisiko, kulturforskjeller og mulig kompetanseflukt.
  • Kan bli personavhengig dersom nøkkelpersoner slutter.
  • Oppkjøp løser ikke automatisk Norconsults interne silo- og insentivutfordringer.
  • Kan bli dyrt dersom markedet allerede priser cyberkompetanse høyt.

Viktige risikoer

  • Man kjøper kapasitet, men ikke nødvendigvis organisatorisk gjennomføringsevne.
  • Eksternt miljø kan bli isolert i Norconsult i stedet for integrert.
  • Uklare roller mot eksisterende fagmiljøer kan skape friksjon.

Passer best når: Rask oppskalering av spisskompetanse, spesielt innen OT-cyber, revisjon, hendelseshåndtering, IEC 62443 eller sikkerhetsarkitektur.

Forutsetninger for å lykkes: Må kombineres med intern kraftsentermodell, tydelig integrasjonsplan og retensjon av nøkkelpersoner.
